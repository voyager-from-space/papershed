Your LaTeX source says more than your paper does.

Comments, old drafts, a photo's GPS position, a password you typed into a % line. Drop the project zip you are about to post, for example to arXiv. papershed strips comments, drops files the paper never uses, removes image metadata, flags what looks like a leak and checks your abstract and size against arXiv's rules. You get a clean zip back. It all runs in this tab; nothing is uploaded.

        Rules from arXiv's page on metadata fields. Entries marked "papershed note" are not arXiv rules. arXiv does not publish exactly how it counts characters, so keep some margin.

        Size for arXiv

          arXiv's support page says "The current submission size limit is 50MB" and does not say whether that counts the zip or the unpacked files, or whether MB means 1,000,000 or 1,048,576 bytes, so papershed checks both sizes against 50,000,000 bytes. The 2 MB per file and 34 megapixel lines come from arXiv's page on oversized submissions and its support page (dated 26 March 2021). A size exception can be requested when the limit is a problem.

          Does it still build?

          Compiles the cleaned project in this tab with TeX Live running as WebAssembly. The first check downloads about 177 MB, and about 440 MB if your paper needs packages beyond the common set. It is kept in this browser, so later checks start in seconds. Your files are not uploaded.

            Removed files

              The zip also has a CLEAN-REPORT.txt with file names and counts, never secret values. Delete it before you upload if you don't want it in the bundle.

              What it checks

              • Comments and unused files. % comments, comment and \iffalse blocks, and files the paper never reaches.
              • Image and PDF metadata. GPS and camera data in photos; author and tool fields in PDF figures, also when they are stored compressed.
              • Possible leaks. Passwords, keys, private cloud links, email addresses and \todo leftovers, including inside the comments it removes.
              • arXiv abstract. Length against the 1,920 characters arXiv allows, and characters its form rejects.
              • arXiv size. The 50 MB limit on the zip and the unpacked files, plus arXiv's per-file and megapixel hints.
              • A build check. Compiles the cleaned project in this tab, so you find out here if cleaning broke it.

              Related: arxiv-latex-cleaner from Google Research is a command-line tool that cleans a LaTeX folder for arXiv, and papershed's cleaning rules were inspired by it. papershed is a separate implementation that runs in the browser, and the list above is where it spends its effort.
